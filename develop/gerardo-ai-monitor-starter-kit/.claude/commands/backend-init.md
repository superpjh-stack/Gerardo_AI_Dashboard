대상: $ARGUMENTS

프로젝트 루트에서 AGENTS.md, goal.md, decisions.md, progress.md를 먼저 읽는다.
이 파일은 작업 프롬프트이며 현재 앱 구현 여부를 먼저 확인한다.

backend/CLAUDE.md와 관련 계약을 읽는다. 구현 요청 범위에서만 호환 버전·lock·FastAPI·SQLite 구조를 마련한다. 기존 코드가 있으면 재생성하지 않는다. 현재 가능한 실행 명령을 README에 기록한다.

결과는 변경 파일·검증 명령과 결과·미검증·남은 일로 보고한다.
