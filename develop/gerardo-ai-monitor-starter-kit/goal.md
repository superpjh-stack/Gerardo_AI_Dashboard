# 제품 목표

## 성공 기준
대시보드 첫 화면에서 오늘 한 일, 수집된 사용량, 확인할 일을 10초 안에 파악한다.
작업 요약에서 원본 근거로 이동하며, 수집되지 않은 데이터를 수치로 오해하지 않는다.

## 첫 버전
- 세 도구의 연결 가능 여부·마지막 동기화·오류 표시
- 오늘/이번 주/이번 달 및 프로젝트 필터
- 도구별 활동 카드, 프로젝트별 타임라인, 토큰 분석
- 근거 기반 규칙형 작업 일보, 메모, 사용자 완료 확인
- 로컬 수집과 저장, 원본 읽기 전용

## 이후
AI 바통 터치 후보, 토큰 영수증 고도화, 주간 회고, 작업 별자리.

## 범위 밖
AI 자동 실행·제어, 코드 자동 병합, 팀 SaaS, 결제, 외부 공개, 정확한 생산성 순위, 추정 잔여 한도.
원격 요약 모델 호출은 별도 선택 기능이다.

## 완료 판정
각 제공 가능한 연동이 fixture와 실제 허용 소스에서 검증되고, 미지원 연동도 정상 상태로 표현되어야 한다.
contracts/의 집계 규칙과 docs/acceptance.md의 해당 시나리오를 충족해야 한다.
세 도구의 토큰을 전부 확보해야만 MVP가 되는 것은 아니다. 무엇이 수집되는지 정확히 보여주는 것이 조건이다.
