# 실제 활동 기록의 VPS 동기화 설계

## 요청과 성공 기준
사용자가 노트북의 실제 AI 활동 기록을 기존 Hostinger VPS 1934103 대시보드로 전송하도록 요청했다.
인증된 사용자만 실제 활동을 조회하고, 로컬과 서버의 이벤트 수 및 토큰 집계가 일치하면 첫 전송 완료로 판정한다.
원본 대화, 코드, 도구 인자, 인증정보는 전송하지 않는다.

## 확인한 현재 상태
- 서버 공개 주소 http://187.52.127.215:18788 은 합성 데이터 전용이다.
- 기존 FastAPI 앱은 local/demo 모드만 지원하며 원격 수신·사용자 인증 기능이 없다.
- 로컬 Store는 정규화 이벤트, 소스 상태, 메모, 확인 기록을 SQLite에 저장한다.
- Claude와 Codex의 알려진 JSONL 경로를 읽는다. Antigravity는 지원 가능한 기록 경로가 확인되지 않았다.
- VPS의 443 포트는 기존 다른 서비스의 Caddy가 사용 중이다. 기존 서비스 설정은 변경하지 않는다.

## 접근 방식
권장: 별도 인증된 HTTPS 수신 API에 허용된 메타데이터만 전송한다. 기존 수집기를 재사용하고 재전송을 멱등하게 처리한다.
대안: DB 전체 복사. 구현은 짧지만 절대 경로·메모까지 포함하고 서버 데이터와 충돌하기 쉬워 사용하지 않는다.
대안: 사설 VPN 전용 서비스. 공개 노출은 줄지만 다른 기기의 별도 접속 설정이 필요하다.

## 전송 범위
포함: 이벤트 ID, 도구·모델, 해시 처리된 세션 및 프로젝트 ID, 프로젝트 표시명,
활동 종류와 시각, 토큰 증분·누적 관측값, 캐시 의미, 측정 품질, 파서 버전, 도구 호출 이름,
수집 성공 시각·범위·누락 상태.
제외: 원문 JSONL, 대화·프롬프트, 코드, tool arguments, 절대·상대 파일 경로, 사용자 메모,
인증 파일·환경변수. 출처 참조는 로컬 경로 대신 해시 참조로 바꾼다.
프로젝트명과 모델명은 메타데이터에 포함되므로 인증 없이 조회할 수 없어야 한다.

## 데이터 흐름
1. 지정된 Claude/Codex 경로를 읽기 전용으로 재수집한다.
2. 전송 전 허용 필드만 추출하고 스키마 검증한다. 미수집 null과 0을 구분한다.
3. HTTPS 인증 수신 API로 제한된 크기의 배치를 보낸다.
4. 서버는 기기 ID·이벤트 ID에 따라 UPSERT하고 수신 배치를 트랜잭션으로 반영한다.
5. 실패한 배치는 로컬에서 재시도할 수 있으며 성공 응답 이후에만 체크포인트를 갱신한다.
6. 전체 전송 완료 뒤 소스 상태와 마지막 수신 시각을 갱신한다.

첫 구현은 수동 전송 명령과 첫 전송 검증까지다. 사용자 요청 없이 상시 실행이나 자동 시작 작업은 설치하지 않는다.

## 접근 보호와 배포
실데이터용 private 모드를 추가한다. 설정이 빠지면 서버를 시작하지 않는다.
읽기 인증과 전송 전용 자격 증명을 분리하고, 인증 없는 모든 데이터 조회를 차단한다.
로그인 세션은 Secure·HttpOnly·SameSite 쿠키로 관리하며 만료·로그아웃을 지원한다.
인증 실패 제한과 CSRF 방어를 적용하고 자격 증명은 Git·URL·로그에 남기지 않는다.
서버에서 소스 동기화 버튼은 노트북 직접 수집을 시도하지 않고 마지막 수신 상태를 안내한다.

기존 443 서비스를 유지한다. 사용자 도메인이 있으면 그 주소를 사용하고, 없으면 IP 기반 DNS 이름과 별도 HTTPS 포트를 사용한다.
인증서 발급과 외부 인증 차단을 먼저 검증한 후 실제 기록을 전송한다.
현재 공개 체험판은 유지하며 실제 DB 볼륨과 분리한다.
인증 수단의 비밀값은 공유 채팅 대신 로컬 비공개 파일 또는 사용자 직접 설정으로 전달한다.

## 검증
- 인증 없는 overview/events/projects/tasks 및 정적 우회 경로에서 실제 데이터가 보이지 않는다.
- 잘못된 전송 자격 증명, 잘못된 출처, 과도한 크기, 미허용 필드를 거부한다.
- 동일 배치 두 번 전송해도 이벤트·토큰 합계가 늘지 않는다.
- 일부 배치 실패 후 재시도하고 기존 정상 데이터를 유지한다.
- 실제 전송 전 payload에 원문·경로·메모·비밀값이 없는지 검사한다.
- 첫 전송 후 도구별 이벤트 수와 전체 기간 토큰 집계를 로컬과 비교한다.
- Antigravity는 미연결로 표시하며 합성 데이터를 실제 수치로 대체하지 않는다.

## 롤백
새 private 서비스만 중지해 공개 체험판으로 돌아간다. 원본 로그와 로컬 DB를 수정·삭제하지 않는다.
