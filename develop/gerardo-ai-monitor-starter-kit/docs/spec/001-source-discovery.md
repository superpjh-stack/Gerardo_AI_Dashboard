# SRC-001-A · 연동 소스 조사

상태: 1차 조사 완료. Claude/Codex 구현에 필요한 필드를 확인했다. Antigravity는 연결 미확인이다. 결과는 docs/source-capabilities.md와 progress.md를 따른다.

## 목적
이 노트북의 세 도구에서 실제 확보 가능한 데이터와 제약을 확인한다.
## 범위
설치 형태·버전, 사용자 지정 기록 위치, 공식 내보내기/연동 정보, 비식별 fixture.
앱 제어, 인증정보 접근, 전체 홈 탐색, 수집기 구현은 제외한다.
## 절차
1. 필요한 소스 경로를 최소 범위로 확인한다.
2. docs/source-capabilities.md의 세 행을 근거와 함께 채운다.
3. 필드 의미, 누적/증분, 캐시, 시간대, ID를 대조한다.
4. 허용된 비식별 fixture 또는 합성 fixture와 기대값을 docs/input에 기록한다.
5. M1의 첫 어댑터와 미지원 대안을 정한다.
## 완료 조건
세 도구에 조사 상태와 증거가 있으며, 모르는 값은 미확인으로 남고 차단 이유가 명시됨.
원본·비밀의 복사 없이 파서 구현에 필요한 최소 계약이 도출됨.
