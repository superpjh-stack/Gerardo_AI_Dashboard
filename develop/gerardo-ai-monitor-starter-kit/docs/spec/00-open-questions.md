# 미결 사항

기본 UI·계약 기획은 아래 답 없이 진행할 수 있다. 실제 연동 구현은 해당 항목 확인 후 진행한다.

| ID | 질문 | 기본 처리 | 해소 시점 |
|---|---|---|---|
| Q-01 | 각 도구의 설치 형태·버전과 허용 기록 경로? | 미확인 | M0 |
| Q-02 | 토큰·캐시·잔여 한도가 실제 제공되는가? | 미수집 | M0 |
| Q-03 | 추적할 프로젝트 경로와 별칭? | 미분류 그룹 | M0/M1 |
| Q-04 | API 비용·정액 구독료도 입력할 것인가? | 토큰 우선, 비용 미설정 | 사용량 확장 |
| Q-05 | 외부 모델로 요약할 것인가? | 로컬 규칙형 요약 | 후속 기능 |
