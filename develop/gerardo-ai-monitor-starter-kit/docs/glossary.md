# 용어

- 도구(provider): Claude, Codex, Antigravity. 모델과 별개.
- 세션: 도구의 대화·작업 묶음. 단순 앱 실행 시간과 다름.
- 이벤트: 수집한 활동 사건 하나.
- 근거(evidence): 세션 기록·검증 결과·커밋 등의 확인 가능한 참조.
- 실측: 소스에서 직접 확인한 값. 추정: 명시한 계산·가정으로 도출한 값.
- 수동: 사용자가 입력한 값. 미수집: 제공되지 않거나 수집되지 않은 값.
- coverage: 수집 범위와 누락·추정 항목의 현황. 미지원 항목을 100%로 표현하지 않음.
- 증분: 구간에서 추가된 사용량. 누적: 동일 counter 시작점부터의 총량.
- 검증됨: 성공 검증 근거 존재. 사용자 확인 완료와 별도 상태.
