# 제품 기획

## 콘셉트
“세 AI가 쓴 자원과 함께 만든 결과를, 제라도의 하루로 모으다.”
비용 가계부·작업 일지·작업 관제실 중, 사용량과 결과를 연결하는 관제실을 선택한다.

## 사용자 흐름
첫 화면 브리핑 → 확인할 작업 → 세션과 변경·검증 근거 확인 → 메모 또는 완료 확인.
사용량 화면 → 프로젝트/도구 필터 → 많이 사용한 세션 → 작업 결과 확인.

## 첫 화면
제목과 날짜/프로젝트 필터 → 오늘의 브리핑 → 수집 토큰/활동 세션/확인 완료/검토 대기 → 세 도구 카드 → 타임라인 → 프로젝트 요약.
성공/실패를 색상만으로 전달하지 않는다. 카드의 최신 활동과 수집기 상태를 분리한다.

## 특색 기능
- 작업 일보: 근거가 있는 사건을 규칙형 문장으로 요약. 각 문장에 evidence ID 연결.
- 내일의 나에게: 마지막 검증 결과와 남은 확인을 사용자 메모와 함께 표시.
- AI 바통 터치: 동일 프로젝트의 세션 연결 후보. 사용자 확인 전에는 확정 협업으로 표현하지 않음.
- 토큰 영수증: 작업별 사용량, 포함된 세션, 결과, 증거를 한 장에 표시.
- 작업 별자리: 프로젝트와 작업 연결을 탐색하는 후속 시각화. MVP에는 제외.

## 핵심 제약
도구마다 수집 가능한 정보가 다를 수 있다. 토큰 null, 연결 불가, 부분 수집도 제품의 정상 상태다.
활동 시간은 기록 기반 추정이며 사람의 노동 시간 또는 절약 시간으로 환산하지 않는다.
