# UI 방향

제목: 제라도의 AI 활동 모니터링. 부제: 세 AI와 함께 만든 오늘의 기록.
짙은 네이비 배경(#101827), 밝은 본문(#EDF2F7), 차분한 경계(#2D3A50).
도구 구분색은 Claude 살구(#F2B08D), Codex 민트(#79D9BC), Antigravity 보라(#B8A0F5).
이는 내부 구분색이며 공식 브랜드 지정이 아니다. 구현 시 실제 대비를 검증한다.

1440px: 상단 필터, 브리핑, 지표 4개, AI 카드 3개, 타임라인 2/3 + 확인할 일 1/3.
1280px: 동일 읽기 순서 유지, 공간에 따라 아래 영역을 세로 배치.
390px: 필터와 카드 세로 배치, 시간축을 목록으로 전환. 수치와 단위 줄바꿈을 통제한다.

0 = 확인된 사용량 없음. — = 미수집. 추정은 라벨과 설명을 항상 제공한다.
차트마다 표 또는 텍스트 요약 제공. 색뿐 아니라 아이콘·상태 문구를 사용한다.
로딩/빈 상태/연결 끊김/부분 수집/원본 없음 상태를 각각 설계한다.
새 이벤트 강조는 짧고 절제하며 reduced-motion을 따른다.
첫 실행 안내는 “수집 소스를 연결하면 활동이 표시됩니다”. 데모는 명시적으로 켜야 보인다.

## 모바일 보완 · 2026-10-31
- 720px 이하에서 하단 고정 메뉴(홈·활동·프로젝트·토큰·소스), safe-area 및 콘텐츠 하단 여백.
- 모바일 본문 13~16px, 입력 필드 16px, 주요 터치 영역 44px 이상. 필터는 세로 배치.
- 지표 2열, 도구·프로젝트 카드 1열, 활동 목록은 프로젝트/요약/사용량을 나눈 행으로 표시.
- 긴 기간 차트와 수치 표만 내부 가로 스크롤. 페이지 자체의 가로 넘침을 방지.
- 작업 상세는 전체 높이 화면, 고정 닫기 영역, 2열 토큰 분해, 세로 메모 버튼. 열려 있을 때 배경 스크롤 잠금.
- 로그인 카드에 border-box·유동 폭·safe-area 적용. 320px에서도 입력과 버튼이 화면 안에 들어온다.

검증: 로컬 합성 데이터로 Chrome의 320/390px 프레임에서 프로젝트·활동·로그인,
추가 305/375px 콘텐츠 폭에서 대시보드·소스·월간 차트·작업 상세의 가로 넘침 없음 확인.
태블릿 768px 및 데스크톱 1280px 프레임에서도 가로 넘침 없음(시스템 스크롤바 포함 콘텐츠 폭 753/1265px).
모바일 화면의 활성 버튼·입력·select·summary 높이 검사 후 작은 검색 입력 영역을 44px로 보완했다.
실제 iOS/Android 기기의 키보드·노치 동작은 실기기에서 별도 확인이 필요하다.
