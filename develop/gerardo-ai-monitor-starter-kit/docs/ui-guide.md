# UI 방향

제목: 제라도의 AI 활동 모니터링. 부제: 세 AI와 함께 만든 오늘의 기록.
짙은 네이비 배경(#101827), 밝은 본문(#EDF2F7), 차분한 경계(#2D3A50).
도구 구분색은 Claude 살구(#F2B08D), Codex 민트(#79D9BC), Antigravity 보라(#B8A0F5).
이는 내부 구분색이며 공식 브랜드 지정이 아니다. 구현 시 실제 대비를 검증한다.

1440px: 상단 필터, 브리핑, 지표 4개, AI 카드 3개, 타임라인 2/3 + 확인할 일 1/3.
1280px: 동일 읽기 순서 유지, 공간에 따라 아래 영역을 세로 배치.
390px: 필터와 카드 세로 배치, 시간축을 목록으로 전환. 수치와 단위 줄바꿈을 통제한다.

0 = 확인된 사용량 없음. — = 미수집. 추정은 라벨과 설명을 항상 제공한다.
차트마다 표 또는 텍스트 요약 제공. 색뿐 아니라 아이콘·상태 문구를 사용한다.
로딩/빈 상태/연결 끊김/부분 수집/원본 없음 상태를 각각 설계한다.
새 이벤트 강조는 짧고 절제하며 reduced-motion을 따른다.
첫 실행 안내는 “수집 소스를 연결하면 활동이 표시됩니다”. 데모는 명시적으로 켜야 보인다.
