# 초기 버전 기획·디자인·구현 계획과 이행 기록

사용자의 2026-10-31 개발 시작 요청에 따라 기존 가이드·스타터킷을 기준으로 순차 구현했다.
이 문서는 현재 구현 범위와 후속 단계를 함께 명시한다. 다른 AI 에이전트를 자동 실행하지 않았다.

## 기획 결정
오늘 한 일 / 수집 사용량 / 확인할 일을 먼저 보여준다. 수집 가능 여부와 누락을 숨기지 않는다.
작업의 첫 단위는 세션이다. 사용자 확인은 모델 발언이나 테스트 성공과 분리한다.
현재 요약은 프로젝트 수·세션 수·도구 호출 수에 기반하며 의미 분석 모델을 호출하지 않는다.

## 디자인
네이비 배경, 민트 탐색 강조, 도구별 살구·민트·보라.
좌측 탐색과 상단 필터, 브리핑, 핵심 지표, 세 AI 카드, 차트/프로젝트, 타임라인 순서.
작업 상세는 오른쪽 dialog로 열어 기간과 프로젝트 필터를 유지한다.
960px 아래 아이콘 탐색, 720px 아래 상단 탐색·한 열 카드로 전환한다.
시각 장식은 세 도구가 모이는 작은 궤도 도형뿐이며 실제 수치와 혼동하지 않는다.

## 구현 순서와 결과
1. M0: 허용 로컬 소스 조사. Claude/Codex 필드 확인, Antigravity는 연결 미확인.
2. M1: Python 3.12 uv 환경, 파일 파서, SQLite, 안정 ID와 파일 스냅샷, 체크포인트 트랜잭션.
3. M2: overview, usage, projects, events, sources, session, task 상세·메모·확인 API.
4. M3: React/TypeScript/Vite, 5개 화면과 세션 dialog, 필터·예시·오류·반응형.
5. M4: 규칙형 브리핑·근거 참조·메모·완료 확인.
6. M5: 실제 자료 수집, 중복·회전·롤백 등 15개 테스트, 브라우저 동작 확인.

## 후속
Antigravity 실제 소스 제공 후 어댑터 추가. Git/검증 연결, 의미 기반 작업 분류, 프로젝트 별칭.
모든 문서의 수용 시나리오 전체가 완료된 것은 아니다. progress.md에 실제 실행한 검증만 기록한다.
