# 목표 화면 구성

```text
제라도의 AI 활동 모니터링          [기간] [프로젝트]
오늘의 브리핑 / 마지막 수집 / 부분 수집 안내
[수집 토큰] [활동 세션] [확인 완료] [검토 대기]
[Claude 최근 활동] [Codex 최근 활동] [Antigravity 최근 활동]
[프로젝트별 작업 타임라인           ] [확인할 일]
[사용량 추이와 표                  ] [내일의 나에게]
```

데이터 없는 첫 실행은 소스 연결 안내를 표시한다. 임의 실적 숫자를 넣지 않는다.
화면 ID와 세부 상태는 contracts/screens.md, 시각 기준은 docs/ui-guide.md를 따른다.
