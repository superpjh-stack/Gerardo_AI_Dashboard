# 프런트엔드 참고 지침

먼저 루트 AGENTS.md와 contracts/screens.md, docs/ui-guide.md를 읽는다.
실제 앱 코드는 src/에 있다. React와 TypeScript를 사용한다.
실데이터·데모를 분리하고 데모를 실제 연결 성공으로 표현하지 않는다.
총합과 coverage는 API 응답을 사용한다. UI에서 캐시나 누락값을 임의 계산하지 않는다.
수집 상태와 AI 작업 상태를 구분한다. 카드는 역할 고정 없이 실제 최근 활동을 표시한다.
키보드, 빈 상태, 오류, 부분 수집, 390/1280/1440px를 확인한다.
