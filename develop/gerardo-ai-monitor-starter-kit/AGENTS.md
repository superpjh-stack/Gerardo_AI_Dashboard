# 세 AI 공통 개발 규칙

## 목적과 범위
- 제품명은 “제라도의 AI 활동 모니터링”. Claude, Codex, Antigravity의 활동·토큰·작업 근거를 연결한다.
- 이 폴더가 새 프로젝트 루트다. 현재 React/TypeScript·FastAPI·SQLite 초기 앱이 구현되어 있다. 실행·지원 범위는 README.md와 progress.md를 확인한다.
- 사용자 지시 → 이 규칙 → goal.md → contracts/ → decisions.md → 작업 스펙 순서로 읽는다. 충돌은 명시하고 정합화한다.
- 다른 사업 폴더와 기존 develop의 MES 자료를 수정하지 않는다.

## 데이터 불변조건
- provider(도구)와 model을 분리한다. 도구를 특정 모델이나 업무 역할에 고정하지 않는다.
- 미수집은 null이며 0이 아니다. 실측·추정·수동·미수집과 출처를 보존한다.
- 누적 사용량과 증분 사용량을 중복 합산하지 않는다. 캐시 포함 여부를 모르면 총합을 단정하지 않는다.
- API 환산액, 실제 사용료, 월 구독료, 한도는 별도 항목이다. 확인되지 않은 잔여 한도를 만들지 않는다.
- Git 변경만으로 AI 작성자를 확정하지 않는다. 모델의 완료 발언을 검증 완료로 바꾸지 않는다.
- 예시 데이터는 synthetic으로 표시하고 실데이터 집계에서 제외한다.

## 구현과 검증
- docs/source-capabilities.md에 실제 설치 형태·버전·기록 형식·지원 범위를 확인한 후 어댑터를 만든다.
- 원본 앱 로그·프로젝트·Git은 읽기 전용. 수집 상태, 요약, 메모는 전용 로컬 저장소에만 쓴다.
- 전체 홈 디렉터리를 무차별 탐색하지 않는다. 지정한 소스 경로만 읽고 인증정보는 출력하지 않는다.
- 기본 서버 바인딩은 127.0.0.1. 외부 AI 요약·원문 전송은 기본 비활성이다.
- backend/frontend 지침과 관련 계약을 읽고 작은 작업 단위로 구현한다.
- 검증은 중복 수집, null, 시간대 경계, 캐시, 실패 복구 등 실제 동작을 확인한다.
- 실행하지 않은 테스트와 연동은 완료로 보고하지 않는다.

## 협업
- 기본은 순차 작업이다. 사용자 요청 없이 별도 에이전트를 자동 실행하지 않는다.
- docs/handoff.md에 작업 ID·담당 도구·변경 파일·완료 조건·검증 결과를 남긴다.
- 공용 계약·lock·DB 마이그레이션 파일은 한 번에 한 담당자만 수정한다.
- 사용자 변경을 덮어쓰지 않는다. push·배포·외부 공유는 요청 범위를 따른다.
