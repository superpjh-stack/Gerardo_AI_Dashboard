# 화면 계약 v0.1

| ID | 경로 | 내용 | 필수 상태 |
|---|---|---|---|
| DASH-001 | / | 브리핑, 지표, AI 카드, 타임라인 | 첫 실행, 부분 수집, 정상, 오류 |
| ACT-001 | /activity | 시간순 활동과 필터 | 없음, 로딩, 일부 실패 |
| PRJ-001 | /projects | 프로젝트별 활동·검증 현황 | 미분류 프로젝트 포함 |
| USG-001 | /usage | 토큰 추이, 도구·프로젝트 분해 | 미수집, 부분값, 추정 |
| TASK-001 | 현재 화면의 세션 dialog | 작업 근거, 메모, 완료 확인 | 근거 없음, 원본 이동/삭제 |
| SRC-001 | /sources | 소스 등록·상태·지원 범위 | 미설정, 지원, 부분 지원, 미지원, 수집 오류 |

공통 필터: 기간, 프로젝트, 도구. 기간 경계는 events.md를 따른다.
작업 상세로 이동할 때 필터를 유지한다. 차트에는 같은 데이터를 읽을 수 있는 표를 제공한다.
도구 카드: 수집기 상태·최근 활동 시각·수집 토큰·최근 작업. 앱 실행 여부로 작업 중을 추측하지 않는다.
