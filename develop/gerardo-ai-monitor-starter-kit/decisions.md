# 설계 결정 초안

이 문서는 요청된 기획을 개발용 기준으로 구체화한 제안이다. 실제 연동·버전 확인 결과에 따라 변경한다.

| ID | 결정 | 이유 |
|---|---|---|
| D-001 | 개인용 로컬 앱, React/TypeScript + FastAPI + SQLite | UI·수집·저장을 분리하고 서버 운영 부담 축소 |
| D-002 | 도구별 어댑터와 공통 이벤트 | 서로 다른 소스 지원 범위를 보존 |
| D-003 | null·품질·출처·coverage 필수 | 미수집을 사용량 0으로 오인하지 않음 |
| D-004 | 원본 읽기 전용, 정규화 저장소만 쓰기 | 원래 개발 도구의 기록 보존 |
| D-005 | 초기 요약은 규칙형 | 외부 전송과 추가 토큰 소비 없이 근거 확인 |
| D-006 | 기본 순차 작업과 인수인계 문서 | 세 도구의 파일 충돌 예방 |

변경 시 이유, 영향받는 계약과 마이그레이션 여부를 함께 기록한다.

## 2026-10-31 구현 결정
- D-007: UI 포트 5188로 확정. 기존 5173 앱과 구분. API는 8765.
- D-008: 첫 수집 범위는 도구별 최근 수정 100개 JSONL. 한도와 총 파일 수를 화면에 표시.
- D-009: TASK-001은 독립 URL 대신 필터를 유지하는 dialog로 구현.
- D-010: 세션 프로젝트는 최초 관측 작업 폴더로 유지. 도중 cwd 변경으로 같은 세션을 분할하지 않음.
- D-011: 관측한 형식의 로컬 파서 사용. 형식 변화 시 파서 버전과 테스트 갱신.
- D-012: 이벤트 원본별 스냅샷과 고유 ID 조회 테이블 분리. 회전·복사 시 중복 방지와 이력 보존.
- D-013: 사용자 승인에 따라 VPS private 모드를 별도로 추가. demo 서비스와 데이터 볼륨을 분리한다.
- D-014: 자동 전송을 설치하지 않고 수동 스냅샷 전송을 제공한다. 배치 전체 해시/개수를 검증 후 원자 교체한다.
- D-015: 기존 443 서비스 유지. 별도 Caddy의 80 인증서 검증 및 18790 HTTPS를 사용한다.
